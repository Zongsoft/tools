# Zongsoft.Tools.Regular

[English](README.md) | [简体中文](README.zh-Hans.md)

A Windows application for testing regular expressions. It shows matches, groups, and captures, supports regex options, and can open or save pattern files.

## Requirements

Windows x64 and the .NET 10 Windows Desktop Runtime.

## Install and run

```powershell
dotnet tool install -g Zongsoft.Tools.Regular
dotnet regular
```

The command opens the Regular window. You can also run `dotnet-regular` directly if your .NET global tools directory is on `PATH`.

## Update or uninstall

```powershell
dotnet tool update -g Zongsoft.Tools.Regular
dotnet tool uninstall -g Zongsoft.Tools.Regular
```
